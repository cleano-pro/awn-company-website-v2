# موقع شركة عَون — نسخة GitHub Pages

هذه نسخة ثابتة من موقع عَون جاهزة للرفع إلى GitHub Pages. لا تحتاج إلى Node.js أو خادم خلفي؛ ارفع الملفات الموجودة في هذه الحزمة إلى جذر المستودع، مع الحفاظ على مجلد `assets` كما هو.

الملفات الأساسية هي `index.html` و`styles.css` و`main.js`. جميع الصور المستخدمة في التصميم موجودة محليًا داخل `assets`، وجميع الروابط إليها نسبية بصيغة `./assets/...` حتى تعمل داخل رابط المشروع:

`https://cleano-pro.github.io/awn-company-website/`

## النشر

من إعدادات المستودع على GitHub افتح **Settings → Pages**، اختر **Deploy from a branch**، ثم اختر فرع `main` ومجلد `/ (root)` واضغط **Save**. بعد اكتمال النشر افتح رابط الموقع.

تم تضمين صورة `services.webp` أيضًا ضمن الأصول المحلية لأنها جزء من حزمة الصور الأصلية للمشروع، حتى لو لم تكن مستخدمة مباشرة في تخطيط الصفحة الحالي.
